# novathesis 7.11.x — Source Code Audit Report

**Scope:** template source at branch `7.11.x` (v7.11.0, 2026-06-13). Findings are ordered by severity within each section.

## 1. Critical issues

**1.1 CI never tests pull requests.** [build-template.yml:23](.github/workflows/build-template.yml:23) checks out `ref: main` unconditionally, but the workflow also triggers on `pull_request`. Every PR build silently compiles `main` instead of the PR branch, so CI green on a PR means nothing. Remove the `ref:` line (the default checkout is correct for both triggers). Two related problems in the same file: `permissions: write-all` (line 13) is far too broad for a build job — use `permissions: contents: read`; and `if: github.actor != 'my_bot_account'` (line 18) is a leftover placeholder.

   - **⏳ DEFERRED 1.2 Invisible white-text blocks embedded in every generated thesis.** `\@ntfixspacing` ([nt-render-matter.sty:41](novathesisFiles/StyFiles/nt-render-matter.sty:41)) renders the string *"The **nova**thesis template (v…) \cite{novathesis-manual} @ date (12cc9022…md5)"* plus a whole bibliography block in white 0.01pt type, and `\printcompactbib` ([nt-render-matter.sty:602](novathesisFiles/StyFiles/nt-render-matter.sty:606)) hides a similar `\bibname (md5-hash)` heading the same way. This text is invisible on screen but fully extractable (copy/paste, screen readers, PDF/A text layer, Turnitin-class tools). For a *thesis* template this is a real integrity/compliance exposure: hidden text in an academic submission can be flagged by plagiarism detectors or violate university submission rules, and the student has no idea it's there. Recommend making the template attribution visible (a colophon line is normal and dignified) or at minimum documenting it prominently and providing an opt-out.

**1.3 The `mainmatter/pre` hook fires twice.** `\ntthesismainmatter` runs `\NTRunHook{mainmatter/pre}` at both [nt-render-matter.sty:267](novathesisFiles/StyFiles/nt-render-matter.sty:267) and [line 273](novathesisFiles/StyFiles/nt-render-matter.sty:273). Any school or user code attached to that hook (counter changes, spacing, `\addtocontents` writes) executes twice. Delete one of the two calls.

**1.4 Commit history integrity.** Commit `aab2152f` is labeled *"feat(auth): implement oauth2 authentication flow — BREAKING CHANGE: legacy token authentication removed"* but actually contains documentation for `print/otherlists`, `print/glossaries` and `abstract/title` options. Nothing malicious is in the diff — I checked — but a security-sounding commit message that doesn't match its content in a widely-used template will alarm anyone auditing the supply chain (it alarmed me). Consider rewording it before it reaches `main`, and note that `BUILD-PROPOSAL.md` (deleted in `6fd27f5d`) is currently staged for re-addition in the working tree — likely unintended.

**1.5 `-shell-escape` is unconditional.** The [Makefile:53](Makefile:53) passes `-shell-escape` to every build, and `\ntcheckfonts` ([nt-core.sty:747](novathesisFiles/StyFiles/nt-core.sty:747)) downloads fonts by interpolating URLs/paths into `curl`/`wget`/`python` shell commands without quoting. Combined, any school `.clo` or config file can execute arbitrary shell commands on a student's machine. Today all inputs are repo-controlled, so the practical risk is moderate, but consider: restrict to `-shell-restricted` where minted/makeglossaries allow, quote all interpolated shell arguments, and document why shell escape is required.

## 2. Minor bugs and non-conformances

1. **Spurious class warning on every build:** `nt-spine.sty` declares itself with `\ProvidesExplPackage` but is loaded via `\file_input:` from class context ([nt-setup.sty:1119](novathesisFiles/StyFiles/nt-setup.sty:1119)), so every log contains *"You have requested document class 'novathesis' but the document class provides 'nt-spine'"* (confirmed in `AUXDIR/template.log:1894`). Load it with `\RequirePackage` like its siblings.
   - **⏳ DEFERRED (attempted 2026-07-18, not fixed).** The two obvious fixes both break the build with an `\ifnum … V` / *"Missing `\begin{document}`"* error, confirmed in isolation:
     - `\RequirePackage{nt-spine}` (the suggested fix) — nt-spine is not `\RequirePackage`-safe.
     - Commenting `\ProvidesExplPackage` and substituting `\ExplSyntaxOn` … `\ExplSyntaxOff`.
     Root cause: `\ProvidesExplPackage` doesn't just declare the package — it enables the expl3 catcode regime *and* arranges a clean restoration at end of file. nt-spine.sty relies on that (no `\ExplSyntaxOn/Off` of its own; it loads tikz/tcolorbox under expl3 catcodes). A manual `\ExplSyntaxOn/Off` pair doesn't restore identically — a nested package leaves the expl3 catcode stack unbalanced, so the regime leaks into the preamble and corrupts later tokenisation (the stray `V` fed to an `\ifnum`).
     Untried option to revisit: keep `\ProvidesExplPackage` intact and set `\@currname`/`\@currext` to `nt-spine` for the duration of the `\input` in nt-setup.sty, so `\ProvidesExplPackage`'s self-check matches and the warning is silenced without touching the catcode handling. The warning is cosmetic (log-only; no effect on output), so this is low priority.
2. **Duplicate hyperref destinations:** the last build log has ~12 *"destination with the same identifier (table.2.1 … algocf.1)"* warnings, despite the comment at [nt-packages.sty:204](novathesisFiles/StyFiles/nt-packages.sty:204) claiming `hypertexnames=true` prevents them. Table and algorithm anchors still clash (memoir double-caption rendering).
3. **`\ntprintfrontpage` gates on the wrong toggle:** [nt-render-matter.sty:106](novathesisFiles/StyFiles/nt-render-matter.sty:106) tests `print/statement` instead of `print/frontpage` — a copy-paste of `\ntprintstatement`. (The command appears unreachable today, which is itself a smell — see §3.)
4. **Misspelled public command `\TheCandiadteSignature`** ([nt-render-matter.sty:455](novathesisFiles/StyFiles/nt-render-matter.sty:455)) — the typo is now API, used by 4 statement files in `1-FrontMatter/`. Rename to `\TheCandidateSignature` and keep the misspelling as a deprecated alias.
5. **Ignored arguments in signature commands:** `\TheCandiadteSignature`'s `#1` (place) is never used, and `\TheAdvisersSignatures`'s optional `O{20mm}` rule-distance is never forwarded to `\StatementOneSignature` ([nt-render-matter.sty:455-489](novathesisFiles/StyFiles/nt-render-matter.sty:455)). Callers passing "Lisbon" get it silently dropped.
6. **`ntquoting` (non-starred) italicizes only the first token:** `{\ntquotetext#7}` at [nt-render-matter.sty:720](novathesisFiles/StyFiles/nt-render-matter.sty:720) is missing braces — should be `\ntquotetext{#7}` (the starred branch does it correctly).
7. **Probable separator bug for two-person lists:** `\FormatNamesAsList` calls `\seq_use:Neee \l_tmpb_seq {#2}{#3}{#4}` ([nt-render-persons.sty:148](novathesisFiles/StyFiles/nt-render-persons.sty:148)), but `\seq_use:Nnnn`'s first separator is the *between-exactly-two* separator — here it receives the name *prefix* (default empty), and the last-separator optional `#5` is never used. With exactly two advisers (the common case for schools using list format — uminho, ulisboa/fcul), names concatenate with no "and" between them. Should be `{#4}{#3}{#5}`.
8. **Latent error in `\IfFileExistsInDirsTF`:** [nt-core.sty:259](novathesisFiles/StyFiles/nt-core.sty:259) executes `\tl_new:N` (a global declaration) inside the command body — the second invocation would raise "command already defined". It is currently dead code (zero call sites), which is why the build survives; either fix or remove.
9. **Non-reentrant shared flag:** `\l_file_found_bool` is set with `\bool_gset_*` (global set on an `l_`-named local — an expl3 naming violation) and shared across `\IfFileExistsInDirsTF`, `\IfFileExistsCase` and `\InputIfFileExistsInDirsTF` ([nt-core.sty:254-410](novathesisFiles/StyFiles/nt-core.sty:254)); nesting any two of them clobbers the outer result.
10. **`nt-spine` variable declarations:** the box `fontstyle` variables are created with `\dim_new:c … _fontstyle_tl` ([nt-spine.sty:79](novathesisFiles/StyFiles/nt-spine.sty:79)) — a *dimension register* later overwritten as a token list; and `…_extrasep_dim` is used ([lines 163](novathesisFiles/StyFiles/nt-spine.sty:163), [599](novathesisFiles/StyFiles/nt-spine.sty:599)) but never declared — both work only by accident of l3keys auto-creation.

    - **✅ (a) DONE** — SDG heading falls back to English for languages with no `SdgString` (commit `e0c2db88`).

    - **✅ Option A DONE** (commit `cdd0bdc5`). Collapsed the python branches (and fixed their `> /dev/null 2>&1` probe that discarded the version string); fixed the PowerShell probe (`where powershell`); added a portable null device resolved via an e-expanding `\sys_get_shell` variant; replaced the undefined `\sys_shell:n` with `\sys_shell_now:x`; and added post-download file verification (`ntfonts/download-failed` warning) with `curl -f`. ## 3. Code improvement suggestions

- **[√] Remove dead code rather than commenting it out.** ~80 lines of the superseded cover engine remain commented in [nt-setup.sty:819-898](novathesisFiles/StyFiles/nt-setup.sty:819), plus old-implementation comments throughout `nt-setup.sty` (`\ntdepartment`, `\ntmajorfield`, …), the commented `\debuggrid` duplicated in `nt-setup.sty` vs. the live one in `nt-covers.sty`, and unused `\ntprintfrontpage`/`\IfFileExistsInDirsTF`. Git history preserves them.
- **Factor the repeated `\datamatch` hierarchy lists.** The 8–12-entry fallback chains (`\@DOCTYPE,\@DEGREEACR,#1,key` → … → `key`) are duplicated at least five times in `nt-covers.sty` and twice in `nt-setup.sty`. A single helper that generates the chain from `{store}{suffix-key}` would remove ~120 fragile lines and guarantee consistent lookup order.
- **Adopt proper expl3 conditionals for the file utilities** (`\prg_new_protected_conditional:` with distinct, correctly-scoped booleans) instead of the shared `\l_file_found_bool` — fixes item 2.9 structurally.
- **Unify the option-system stack.** The template currently runs three key-value systems in parallel: `options.sty`+`options-ext` (`/novathesis/...`), l3keys (`nt-spine`, `nt-covers` elements, `aidisclose`), and memstore. That's a big cognitive load for contributors and produces duplicate idioms (`\iftoggle` vs `\bool_if:` vs `\ifoptionequal`). A realistic medium-term goal is migrating `options.sty` usage to l3keys — `options.sty` is essentially unmaintained.
- **[√] `\myprintglossaries`** ([nt-setup.sty:707](novathesisFiles/StyFiles/nt-setup.sty:707)) executes `\newif\ifGlossaryNotEmpty` at print time on every call — hoist the declaration to load time.
- **[√] Error-message hygiene:** use a consistent mechanism (`\msg_new/\msg_error` with a `novathesis` module) instead of mixed `\ClassError`/`\PackageError` (e.g. `\PackageError` inside the class at [nt-setup.sty:920](novathesisFiles/StyFiles/nt-setup.sty:920)), and avoid curly typographic quotes in console messages.
- **[√] Makefile:** `watch` hardcodes `-pdflua` regardless of engine target; a `watch-xe`/`ENG` passthrough would match the rest of the interface.
- **Wire `Scripts/validate-schools.py` (and `make matrix` for a subset) into CI** so school regressions are caught — the current workflow builds only the default nova/fct configuration on one engine.

- **Repository hygiene:** decide the fate of the staged `BUILD-PROPOSAL.md`; drop `Makefile-OLD`; normalize `aidisclose.sty` to 644; consider a commit-message lint (the `oauth2` mislabel would have been caught by a human glance — it looks like an AI-generated message from the wrong context).

So CI can change underfoot on any upstream image rebuild despite the action being SHA-pinned, which partly defeats the pinning work. Either pin by image digest in an explicit container step, or accept it and rely on the matrix to catch breakage. (Found 2026-07-20 while verifying §6.1.)

Either honor it as a real option or remove it.

## 6. Write registers and the `morewrites` dependency (performance)

*Investigated 2026-07-19/20. Origin: pdfLaTeX matrix builds taking ~2× LuaLaTeX time.*

**Root cause.** `morewrites` ([nt-packages.sty:24](novathesisFiles/StyFiles/nt-packages.sty:24)) virtualises pdfTeX's/XeTeX's 16-`\write` pool at a cost of roughly **9× per pass**. Measured on the demo, full clean pdfLaTeX build: **109 s with, 35 s without**. LuaLaTeX (65536 registers) never loads it. Both engines run exactly 4 passes — the template is *not* compiling twice.

**Register ledger** (kernel silently takes 3: `\@unused`, `\@mainaux`, `\@partaux`):

| Owner | Streams |
|---|---|
| memoir (`\verbatim@out`, `\tf@toc`, `\tf@lof`, `\tf@lot`) | 4 |
| pgf/tikz (`\w@pgf@writea`, cover renderer) | 1 |
| biblatex (`\blx@bcfout`) | 1 |
| glossaries (`\glswrite`, `glo@main`, `glo@acronym`) | 3 |
| symbols glossary / `\listofalgorithms` / `\listoflistings` | 1 each, **only when used** |
| document's own packages (e.g. minted → `\FV@OutFile`) | varies |

**Done.**
- `FASTWRITES=1` / `\def\ntnomorewrites{}` skips `morewrites` (commit `f6613308`). Overshooting fails loudly with *"No room for a new `\write`"* rather than silently misrouting a list file to the terminal.
- The symbols glossary is created on demand, only when a symbols file is registered (commit `4b13a212`), dropping the class floor **13 → 12**. Note the demo registers one, so the *demo* still needs `morewrites`; real theses without symbols do not.

### 6.1 ⏳ DEFERRED — bib2gls/`record` mode (the remaining big win)

Phase 0 spike run 2026-07-20. **The working spike lives on the unmerged branch `spike/bib2gls-record-mode`** (commit `b58297d8`, branched off `4b13a212`) — rebase it onto the current tip to resume rather than starting over. **Verdict: technically viable, blocked only on an ecosystem decision.**

Measured with the full demo, pdfLaTeX, `FASTWRITES=1`:

- **All four glossary registers disappear** (`\glswrite`, `glo@main`, `glo@acronym`, `glo@symbols`). Class floor **12 → 9**; the demo gains 4 spare registers and no longer needs `morewrites` at all. Build **42 s vs 109 s**.
- **Output holds up:** 112 pages both, entry set identical, and [glossary-xltabular.sty](novathesisFiles/StyFiles/glossary-xltabular.sty) needs **zero** changes (it is a standard `\newglossarystyle` driving `theglossary`, which `\printunsrtglossary` uses identically). `latexmkrc`'s four `add_cus_dep` + `run_makeglossaries` collapse to one bib2gls rule. Conversion of the 37 entries is mechanical (`convertgls2bib`).
- **CI is fine:** `ghcr.io/xu-cheng/texlive-full:latest` (what the pinned action actually runs) ships **OpenJDK 21** and **bib2gls 4.7**. No workflow changes needed.

Three real work items surfaced:

1. **Location-list plurals regress** — `(pp. 1, 40)` → `(p. 1, 40)` on every entry. `\GlsXtrEnablePreLocationTag` ([nt-packages.sty:260](novathesisFiles/StyFiles/nt-packages.sty:260)) does not fire against bib2gls-built location lists.
2. **Symbol sort order changes.** `convertgls2bib` emits symbols as `@entry` with no `sort` field, so bib2gls sorts on the raw `name` (`\ensuremath{\mu}`). Needs `@symbol` entries with explicit `sort` keys. Collation will also shift for Greek/Portuguese/Chinese schools (ICU instead of xindy) — generally an improvement, but a visible diff needing matrix review.
3. **`\glsaddall` has no equivalent.** [chapter-introduction.tex:14](2-MainMatter/chapter-introduction.tex:14) calls `\glsaddall[types={main,symbols}]`; bib2gls expresses this as per-resource `selection={all}`, so the resource split becomes part of the design and `\glsaddall` must be deprecated in user documents. **A single resource with `selection={recorded and deps}` silently drops uncited entries while the page count stays 112** — so any migration needs entry-set assertions in the matrix, not just "it compiled".

**Migration shape:** dual-mode behind `\ntsetup{glossaries/backend=makeindex|bib2gls}`, defaulting to `makeindex` for a release or two; keep the `\ntaddfile{glossaries}[type]{file}` API and remap it to a `.bib` resource. Files to adapt: `1-FrontMatter/{glossary,acronyms,symbols}.tex` → `.bib`; the glossaries block and `\AtBeginDocument{\@loadglossaryfiles\makeglossaries}` in `nt-packages.sty`; `\@loadglossaryfiles` in `nt-render-matter.sty`; `\printglossary` → `\printunsrtglossary` in [nt-setup.sty:659](novathesisFiles/StyFiles/nt-setup.sty:659); the glossary block in `latexmkrc`; docs in `chapter-manual.tex`, `chapter-latex.tex`, `app-internals.tex`, `app-build.tex`.

**The open question is not technical:** every existing thesis needs `.tex`→`.bib` conversion, and every user needs a local JRE (Overleaf supports bib2gls; assorted student laptops are the risk). Also retires the `automake`/xindy shell-escape invocation — a bonus for §1.5.

**Overall:** the codebase is in good shape for its size and history — the expl3 migration is well along, the school layering is clean, and the build system is modern. The items that genuinely need action soon are the five in §1 (CI checkout, hidden text, double hook, commit mislabel, shell-escape posture) and bugs 2.1–2.7, which have user-visible effects.
