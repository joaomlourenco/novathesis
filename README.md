# novathesis — `gh-pages` branch

This branch used to publish the project's GitHub Pages site at
[joaomlourenco.github.io/novathesis](https://joaomlourenco.github.io/novathesis/) — a Jekyll
site rendered from this README. That site has moved to **[novathesis.org](https://novathesis.org)**,
so this branch now does one thing: `index.html` redirects visitors there.

The template itself — source, documentation, releases — lives on the `main` and `develop`
branches of this repository. The logo and `Showcase/` assets left in this branch are unused
leftovers from the old site; don't add anything new here.
